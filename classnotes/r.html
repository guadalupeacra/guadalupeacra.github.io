Importing, cleaning, transforming, analysing and visualising economic data.

General pattern

Set project path → import data → inspect → clean → transform → analyse → visualise → export.

Principle

Keep raw data untouched and make every transformation explicit and reproducible. Separate raw data, cleaned data, scripts, outputs and written results.
